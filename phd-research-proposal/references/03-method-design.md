# 03 方法与研究设计：让每个结论都能被这套实验回答

审稿人扣分几乎从不因为"方法不够多"，而是因为"读者无法从文字判断这套实验能回答提出的问题"。提分靠设计，不靠堆算法。

## 1. 核心建模思想：保留已知，只学未知

- 先写出领域里已经确定的结构（对数律、守恒律、量纲关系、渐近极限），让机器学习只负责与具体对象有关的那部分。
- 好处要写进 RP：学习问题变小 → 几十个样本就够；极限被写死在函数形式里 → 外推时不会出错；结果可以逐项检查。
- 模板要逐项验证极限（例：g=0 时 ΔU⁺=0；g=1 且 k⁺ 大时斜率 1/κ），并检查模板不会在边界附近给出非物理值（曾有一版模板在起始点附近给出负的 ΔU⁺，被审稿抓出）。

## 2. 方法选择：按交付物要求比较，不按流行度

1. 先写出交付物必须满足的要求，例如：每个网格每步都要算 → 计算便宜；要用于数据外 → 能外推；要满足物理极限；只有约 100 个数据点。
2. 每类方法对照要求说清"能/不能"，并给出在本项目中的角色：
   - 黑箱网络/高斯过程 → 精度参照；
   - 强化学习 → 需大量耦合模拟，不采用（写一句原因即可）；
   - 神经算子（FNO/U-NO/DeepONet/Transolver）→ 适合场到场，作探索性工具（数据少时可靠性受限，不能写成"需要更多数据"又照样训练，前后矛盾）；
   - 符号回归 → 交付显式公式。不同引擎：PySR（遗传编程，可拟合模板）、PSE（GPU 并行枚举，适合小数据，一次一个目标）、贝叶斯机器科学家（公式后验 + 预测不确定度，曾用于 Nikuradse 数据）。
3. 导师问"有没有更好的方法"时，最好的回答是把"选择方法/选择准则"变成可检验的研究内容，而不是自己拍板。
4. 不在 RP 里承诺"开发新架构"。方法创新留作做出数据后与导师商量的方向（面谈时可以口头提）。

## 3. 数据三层分工（审稿最看重）

| 层 | 用途 | 禁止 |
|---|---|---|
| 训练数据 | 特征筛选、参数拟合、符号搜索、内部交叉验证 | 当作最终泛化证明 |
| 开发数据 | 在求解器里比较候选、选最终模型 | 计入最终测试成绩 |
| 最终测试（留出族） | 只报告最终结果 | 参与任何特征、拟合、阈值、选择 |

- 外推检验（例如高雷诺数）单独写隔离规则："直到确定最终表达式的每一步都只用低 Re 数据"。
- 独立样本是"对象"（表面、工况），不是数据点 → 按对象/族做交叉验证，bootstrap 按对象重采样，成组对象整组抽。
- 写清每个误差的参考值从哪里来。重建的参考值（例如由 ΔU⁺ 按外层相似性换算的表面摩擦）要标明是"依赖假设的重建值，不确定度计入排序"，最终精度以独立高保真数据为准。能用已有数据重建就不要加昂贵算例（外部审稿曾建议多加 2 个全展向算例，改用重建法后零新增成本）。

## 4. 公平比较

- 同一候选池里比较不同的选择准则（例："先验拟合最好" vs "求解器中表现最好"），在同一组未见数据上比，才能把"准则的作用"和"候选更多、搜索更久"分开。
- 不同算法流程如果用了不同的拟合方式（例如 PSE 依赖 PySR 的联合拟合结果），要写出来；结论表述为"这些流程"的比较，不宣称算法的一般排名。
- 把"输入表征的价值"（完整高度图 vs 统计量）和"闭合模型的选择"（公式 vs 网络）拆成两个比较。

## 5. 算力与可行性

- 试点：最便宜的条件下用 3–5 个对象走完全链条（数据 → 学习 → 放回工程求解器），先放一个现成模型（如砂粒壁面函数）占位，确保耦合可用。试点同时测单例成本、采样噪声、守恒/受力平衡检查。
- 写出网格量级和最贵的那类算例；写出预算不足时的砍法顺序（先砍探索性部分和样本数，再砍次要对照，核心锚点必须保留）。
- 需要在求解器里筛选候选时：先做非求解器初筛（奇点、非物理值、迭代收敛），每条流程最多 3 个候选，固定开发算例数，总运行数写出来（例：约 40 个粗网格算例）。
- 时间：一个具体项目按 12 个月排；学习/分析在第一批数据产出后就开始，与数据生成重叠。

## 6. 机制与受控实验

- 特征重要性只"提出"哪些特征可能起作用；机制要靠受控对照（例：分布和谱相同、只改峰的组织方式的"孪生表面"）和物理分解（压差/黏性阻力）来"检验"。
- 对照差异的判据：同时超过随机实现之间的离散和采样不确定度。
- 零结果要有价值：报告"数据能排除的最大效应"，并说明零结果本身回答了哪个问题。
- 判据不能循环：判断"是否进入完全粗糙"要用原始数据（ΔU⁺ − (1/κ) ln k⁺ 是否趋于常数），不能用按此关系构造的拟合公式。

## 7. 假设与成功标准

- 假设写成可证伪形式，并说明支持和否定各意味着什么。
- 新增的方法学假设也要可检验，并写清是在哪组数据上检验（"在留出族上、同一候选池"），不要写成已确定的结论。
- 成功标准带数字；换算关系依赖额外条件、正文又不展开时，干脆只写原始指标（案例：删掉"about 5–9% in skin friction"，只留 ΔU⁺ ±0.5 和摩擦 10%），换算放进讲解教程备问；不写"equivalent to"。

## 8. 设计自检清单

- [ ] 每个研究问题都对应到具体的步骤和数据。
- [ ] 每个误差都说清参考值来源；最终测试数据从未参与开发。
- [ ] 外推检验有隔离规则。
- [ ] 比较是公平的（同池、同划分、披露差异）。
- [ ] 计算量有数量级、有上限、有退路。
- [ ] 零结果有解释、有效应下限。
- [ ] 没有循环论证。
- [ ] 每个新增步骤都同步更新了表格、样本数、甘特图。
